Sobre este Prototipo

Este sistema es una solución integral de Gestión de Inventario y Agendamiento Automatizado. El enfoque principal del desarrollo ha sido la arquitectura de servicios en el backend, garantizando la integridad de los datos y la comunicación eficiente entre componentes.

Stack Tecnológico:
  • Backend: FastAPI (Python)
  • ORM: SQLAlchemy
  • Base de Datos: PostgreSQL
  • Frontend: Bootstrap 5 & JS Moderno
  • Notificaciones: SMTP / Gmail API
  • Arquitectura: RESTful API
Estado de las Integraciones:
✅ Notificaciones por Correo Electrónico

Totalmente funcional. El sistema envía confirmaciones automáticas de citas tanto al cliente como al equipo de ventas utilizando protocolos seguros.

⚠️ Integración de WhatsApp (Twilio)

La lógica de mensajería instantánea fue diseñada pero no se encuentra activa en este prototipo debido a los costos asociados a las licencias de la API de Twilio.

Propósito: Demostrar la sincronización en tiempo real entre el stock de vehículos en base de datos y la capacidad de generar flujos de trabajo (workflows) automatizados tras una acción del usuario.
